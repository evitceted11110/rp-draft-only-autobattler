# 視覺規範：午夜契約終端

## 核心語彙

畫面是一座「會發光的契約編譯器」，不是中古卡桌。玩家操作的是四格條件腳本，所有視覺都服務於「讀取 → 排序 → 提交 → 追溯結果」。

## 色彩

- 背景：色相 218–230°、飽和度不超過 28%、亮度不超過 12%。
- 面板：比背景亮 4–8%，以 1px 半透明邊線區隔，不用厚重陰影。
- 主要互動：青綠 `#6de4c1`。
- 危險與敵方：珊瑚紅 `#ff786f`。
- 稀有／條件事件：琥珀 `#f4c95d`。
- 文字：主文 `#eef4f2`，次文 `#91a5a0`；正文對比至少 4.5:1。

## 形狀

- 指令卡左上角用切角，代表可編排的機器語句。
- 事件以膠囊標籤呈現；同事件必須使用同色與同名，不能只靠圖示。
- 四個槽位以垂直編號線連接，讓優先序在縮圖中仍可辨識。
- 敵方攻擊腳本使用等寬數字格，不畫擬真角色。

## 動態

- 拖放以 140–180ms 位移完成，不使用彈簧過衝。
- 戰鬥時間線逐筆揭露；每筆 260–420ms，可切換快速模式。
- 觸發卡只做一次 2px 外框脈衝；生命與護盾改變不得只靠動畫，必須同步顯示數字。
- 尊重 `prefers-reduced-motion`，停用位移與脈衝後仍保留完整資訊。

## 程式化限制

- 不載入外部圖片、影片或圖示字型。
- 所有裝飾由 CSS 漸層、邊框與文字產生。
- 遊戲邏輯不得依賴任何視覺 token。
